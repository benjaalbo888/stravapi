# StravAPI

StravAPI es una API web pública para desarrolladores que necesitan un catálogo ficticio para tiendas de demostración, inventario, dashboards o ejercicios. La portada orienta hacia la referencia interactiva. El catálogo se consulta sin registro y las escrituras están reservadas a administradores.

La API usa Fastify, TypeScript y PostgreSQL. La portada usa HTML y CSS servidos por Fastify. Vercel es el destino de producción indicado en el brief.

La marca se presenta en español con el eslogan «Datos listos para construir.» y una estética técnica oscura. La prioridad de accesibilidad es que un desarrollador pueda leer los ejemplos, seguir enlaces y probar GET con teclado o desde un teléfono.

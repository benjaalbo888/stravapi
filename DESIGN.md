# Diseño de StravAPI

La portada pone una solicitud y su respuesta al lado del eslogan. El ejemplo es el elemento visual principal. La referencia mantiene los controles habituales de Swagger UI y usa la misma tipografía y color de acento.

La interfaz utiliza Instrument Sans para texto, una familia monoespaciada para HTTP y JSON, tinta casi negra en la portada y verde menta para acciones. La referencia conserva fondo claro para distinguir etiquetas, esquemas y resultados. Los enlaces y botones tienen foco visible. La animación de entrada se desactiva con movimiento reducido.
